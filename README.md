## 📖 Tentang Repository Ini

Repo ini adalah **portofolio & self-reminder** perjalanan belajar **Docker Fundamental** yang bersumber dari **Adinusa Free Course**. 

Untuk menghemat penyimpanan dan memudahkan pembacaan (seperti membaca buku), **seluruh materi teori, praktikum lab, dan catatan troubleshooting** digabungkan menjadi satu file komprehensif yang di-*update* secara berkala.
