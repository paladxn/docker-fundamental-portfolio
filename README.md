## 📖 Tentang Repository Ini

Repo ini adalah **portofolio & self-reminder** perjalanan belajar **Docker Fundamental** yang bersumber dari:

- 📚 **Materi & Lab dari [Adinusa](https://adinusa.id/)** — Docker Fundamental Free Course
- 🧪 **Hands-on Lab** yang dikerjakan langsung di environment lab
- 📝 **Catatan teori** yang dirangkum ulang dengan bahasa sendiri

Tujuan:
1. 🎯 **Portofolio** — bukti pembelajaran & konsistensi
2. 🧠 **Self-reminder** — pengingat pribadi kalau lupa command/konsep
3. 🤝 **Sharing** — bantu teman-teman yang juga belajar Docker

## 🗺️ Peta Pembelajaran (Syllabus)

Materi di dalam file *Complete* mencakup 13 topik utama sesuai silabus Adinusa:

| # | Topik | Penjelasan Singkat |
|---|-------|--------------------|
| 01 | **Introduction of Container** | Konsep dasar, VM vs Container, Namespaces & Cgroups |
| 02 | **Introduction to Docker** | Arsitektur Docker, Docker Daemon, Instalasi |
| 03 | **Managing Docker Container** | Lifecycle container, port mapping, exec, resource limits |
| 04 | **Creating Custom Image** | Dockerfile (FROM, RUN, COPY, CMD), Layer Caching |
| 05 | **Docker Compose** | Orkestrasi multi-container dengan file YAML |
| 06 | **Docker Continuous Integration** | Integrasi Docker dengan CI/CD Pipeline |
| 07 | **Docker Swarm & Portainer** | Orchestration bawaan Docker & GUI Management |
| 08 | **Logging Driver** | Manajemen log terpusat (syslog, json-file, dll) |
| 09 | **Health Check** | Memastikan aplikasi di dalam container benar-benar sehat |
| 10 | **Security** | Non-root user, cap-drop, read-only filesystem, secrets |
| 11 | **Storage Driver** | Cara Docker menyimpan layer (overlay2, btrfs, dll) |
| 12 | **Logging & Error Handling** | Exit codes, restart policy, troubleshooting |
| 13 | **Lab Challenge** | Kumpulan soal, quiz, dan solusi error (404, timeout, dll) |

---

## 🎯 Learning Outcome

Setelah menyelesaikan semua materi, diharapkan mampu:

- ✅ Menjelaskan perbedaan **VM vs Container** dan konsep **containerization**
- ✅ Install Docker di Linux / Windows / macOS
- ✅ Mengelola **image**, **container**, **volume**, dan **network**
- ✅ Menulis **Dockerfile** yang efisien & multi-stage
- ✅ Orkestrasi multi-container pakai **Docker Compose**
- ✅ Push / pull image ke **Docker Hub** & private registry
- ✅ Menerapkan **best practices** keamanan & efisiensi image
